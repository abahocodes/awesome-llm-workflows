# Contributing

Thanks for helping make this list better! Adding a tool takes under two minutes.

## The fastest way (no git needed)

1. Open the README in GitHub's web editor: **[click here to edit](https://github.com/abahocodes/awesome-llm-workflows/edit/main/README.md)**.
2. Add one line in the most relevant section:

   ```markdown
   - [Name](https://link) - One-line factual description.
   ```

3. Scroll down, click **Propose changes**, then **Create pull request**. GitHub handles the fork and branch for you.

## Even easier: open an issue

Don't want to touch markdown at all? [Fill in the suggestion form](https://github.com/abahocodes/awesome-llm-workflows/issues/new?template=suggest-a-tool.yml) and we will add the entry for you, with credit.

## Guidelines

- **One addition per pull request** with commit message `Add <Name>`.
- Entry format: `[Name](url) - One-line factual description.` No marketing superlatives.
- The tool must be directly relevant to building, orchestrating, evaluating, or serving LLM workflows.
- Open source projects: link the repository. Hosted products: link the homepage.
- Place the entry in the most relevant section. If unsure, say so in the PR description.
- Dead projects (no activity in 18+ months) may be removed.

We accept both open-source and commercial tools. Disclose affiliation in the PR if you are adding your own product. Affiliated submissions are fine if the entry is factual and the tool is genuinely relevant.

## Review turnaround

We aim to review every PR within 48 hours. If yours has been sitting longer, feel free to bump it with a comment.
